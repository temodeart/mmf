Урсгал сонгоод шууд эхлүүлнэ үү

Хуудас бүр бие даасан бөгөөд хоорондоо жинхэнэ холбоосоор холбогдсон. Зүүн доод булангийн „Урсгалууд“ товчоор энэ жагсаалт руу хэдийд ч эргэж ирнэ.

01

Бүртгэл үүсгэх

Хоосон самбар

Утас → и-мэйл → банкны данс баталгаажуулах → нууц үг → ПИН → ДАН зөвшөөрөл ба MONPEP → нөхцөл → мастер гэрээ → гарын үсэг → Хяналтын самбар (шинэ хэрэглэгч)

 02

Нэвтрэх

Багцтай самбар

И-мэйл ба нууц үг → Хяналтын самбар (эзэмшиж буй бүтээгдэхүүнтэй). Алдааны төлөв, бүртгэл ба нууц үг сэргээх холбоос мөн ажиллана.

 03

Нууц үг сэргээх

Утас эсвэл и-мэйл → баталгаажуулах код → шинэ нууц үг → амжилттай → нэвтрэх

Үндсэн

05
04

Хяналтын самбар

Багцын нэгтгэл, өгөөжийн график, эзэмшил, захиалгын жагсаалт, зарах урсгал (хуудас → ПИН → амжилттай)

 05

Арилжаа

Анхдагч ба хоёрдогч зах → бүтээгдэхүүн шүүх → захиалгын цонх → баталгаажуулах → амжилттай

 06

Миний бүтээгдэхүүн

Эзэмшиж буй бүх хөрөнгө оруулалт — төрөл, хугацаа, статусаар шүүх → зарах

 07

Хэтэвч

Үлдэгдэл, орлого (QPay эсвэл 4 банкны дансаар), зарлага, сүүлийн гүйлгээ, холбоостой картууд

 08

Гүйлгээний түүх

Бүх гүйлгээ — сараар бүлэглэсэн, төрлөөр шүүнэ. Мөр дарж гүйлгээний дэлгэрэнгүй — дүн, огноо, харьцагч, дугаар, шимтгэл, шинэ үлдэгдэл.

Бүтээгдэхүүн

09

Автомат хөрөнгө оруулалт

Мастер урсгал

Ажиллаж байгаа төлөвлөгөөнүүдийн жагсаалт (сард/жилд нийт хасалт) → мөр дарж дэлгэрэнгүй, гүйцэтгэлийн түүх → түр зогсоох, засах. Шинэ төлөвлөгөө: төрөл → давтамж → эрэмбэ (7–8 бүтээгдэхүүн) → эх үүсвэр → нэр → хянах → ПИН.

 10

Зээл

Эрх шалгах → хүсэлт → зөвшөөрөл → идэвхтэй зээл → хаах, хувааж төлөх

Мэдэгдэл

Жагсаалт, уншсан төлөв. Мэдэгдэл бүр өөрийн хамаарах дэлгэц рүү — гүйлгээ → гүйлгээний дэлгэрэнгүй, арилжаа → бүтээгдэхүүн, зээл → зээлийн хуудас.

 12

Профайл

Хувийн мэдээлэл, гэрээнүүд, тодорхойлолт, тохиргоо, гарах

 13

Мэдээ

Зах зээл, бүтээгдэхүүн, зохицуулалт, эдийн засгийн ангиллаар

 14

Суралцах

Хөрөнгө оруулалтын үндэс — богино нийтлэл, видео

 15

Үйлчилгээний нөхцөл

Нөхцөл, нууцлалын бодлого, холбоо барих
Бүртгэлээр орсон бол самбар хоосон төлөвтэй үлдэнэ — „Хяналтын самбар“ урсгалыг дахин нээвэл багцтай төлөв рүү шилжинэ. Хэсэг хуудсанд баруун дээд булангийн Төлөв сэлгүүрээр хоосон, дүүрэн, уншсан төлөвүүдийг харна.
