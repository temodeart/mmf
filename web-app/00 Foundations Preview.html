07 Foundation Rules · F-series Documented rules every later pass applies — grid · focus · date · rate · logo · links · a11y
F-01Fluid content grid

App content grid = grid-template-columns: minmax(0,1fr) 320px. Every grid child gets min-width:0; long labels truncate with ellipsis + title tooltip, never clip or force horizontal overflow. Verified at 1280 / 1366 / 1440 / 1600 / 1920. Utility: .app-grid + .truncate, token --app-rail: 320px.

F-24Global focus ring

One global :focus-visible ring — 2px indigo, 2px offset. Applies to buttons, rows, sort icons, page-size select, dropdown items. Tokens: --focus-ring-color / -w / -offset. Tab through §05 to see it live.

F-13Date format

Timestamps render YYYY.MM.DD, HH:mm in 24h everywhere — no ISO + AM/PM mixing. Via formatDateTime(); calendar-only dates stay formatDate(); relative strings where doc 00 already says so.

2026.05.15, 14:05
avoid 2026-05-15 2:05 PM
F-16Rate format

Annual rate renders 14.5% жилийн — no /Жил/ slash wrapping, mono figure. Via formatRate().

14.5% жилийн
avoid 14.5 % /Жил/

09 Assumptions & Decisions needed
  • formatMNT spacing: README specifies "₮ 48,250,000" with a space. Implemented as ₮ + non-breaking space (U+00A0) + number. Existing inline fmt() helpers in Page 14 omit the space — they should migrate to formatMNT() in Pass 02.
  • Backwards compat: The existing --surface-warning / --border-warning names are preserved in :root. The new --warn-surface / --warn-border are added as explicit values (not aliases) to match brief naming. Migrate callsites gradually.
  • Skeleton reduced-motion: Under prefers-reduced-motion: reduce, shimmer animation is disabled and replaced with a static --line2 fill. No content is hidden.
  • Pass 01 ready — all tokens, formatters, and base patterns confirmed. Say "go" to begin the Component Kit (20 components with full state coverage).
