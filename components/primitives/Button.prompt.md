The MMF action control; intent drives color and a disabled button must state its reason.

```jsx
<Button variant="pos" full onClick={submit}>Авах захиалга өгөх</Button>
```

Variants: primary (indigo) · pos (Buy) · neg (Sell) · ink · ghost. Sizes sm 36 / md 52. When disabled, pass reason so it is never a silent grey.
