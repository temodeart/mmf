Урсгал сонгоод шууд эхлүүлнэ үү

Урсгал бүр бодит дэлгэцүүд дээр ажиллана. Прототип дотор бүх дэлгэц рүү шилжих цэс, буцах товч байгаа — сонгосон урсгал зөвхөн эхлэх цэгийг тогтооно.

Эхлэл ба нэвтрэлт

04
01

Бүртгэл үүсгэх

Хоосон нүүр

Онбординг → утас → и-мэйл → банкны данс баталгаажуулах → карт холбох → нууц үг → ПИН → биометр → ДАН зөвшөөрөл → MONPEP → нөхцөл → мастер гэрээ → гарын үсэг → Нүүр (шинэ хэрэглэгч)

 02

Нэвтрэх

Багцтай нүүр

Нэвтрэх дэлгэц → Нүүр (эзэмшиж буй бүтээгдэхүүнтэй). Мөн энэ дэлгэцээс бүртгэл, нууц үг сэргээх рүү шилжинэ.

 03

Нууц үг сэргээх

Утасны дугаар → баталгаажуулах код → шинэ нууц үг → амжилттай → нэвтрэх

 04

Апп нээх (Splash)

Бүтэн эхлэл

Эхлэлийн дэлгэцээс бүртгүүлэх, нэвтрэх хоёр салаа руу — хэрэглэгчийн жинхэнэ эхний секунд.

Анхдагч зах — худалдан авах

Шинэ гаргалтын жагсаалт → бүтээгдэхүүн → захиалга → баталгаажуулах → ПИН → амжилттай

Хоёрдогч зах — худалдан авах

Зарах санал → захиалга → баталгаажуулах → ПИН → амжилттай

Бүтээгдэхүүн зарах

Багц дахь бүтээгдэхүүн → гэрээ харах → зарах тохиргоо → баталгаажуулах → ПИН → амжилттай

Төлөвлөгөө үүсгэх

9 алхам

Танилцуулга → төрөл → хугацаа → нэгжийн тоо → давтамж → төлөх өдөр → дуусах хугацаа → төсөөлөл → эрэмбэ → төлбөрийн эх үүсвэр → нэр өгөх → хянах → ПИН → идэвхжлээ

 09

Миний төлөвлөгөө

Идэвхтэй төлөвлөгөөнүүд → дэлгэрэнгүй → гүйцэтгэлийн түүх → түр зогсоох, засах

04
10

Данс цэнэглэх

Дүн ба арга → QPay эсвэл банкны шилжүүлэг (4 банкны данснаас сонгоно) → шалгаж байна → амжилттай

 11

Мөнгө татах

Дүн → баталгаажуулах → ПИН → амжилттай. Үлдэгдэл хүрэлцэхгүй төлөв мөн багтсан.

 12

Гүйлгээний түүх

Бүх орлого, зарлага, худалдан авалтын түүх — шүүлтүүртэй. Мөр дарж гүйлгээний дэлгэрэнгүй харна.

 13

Карт холбох ба удирдах

Миний картууд → карт нэмэх → холбогдлоо

Зээлийн хүсэлт

Эрх шалгах → төлбөр (QPay) → баталгаажлаа → хянаж байна → зөвшөөрөгдлөө → ПИН → зээл олгогдлоо

 15

Зээл хаах

Хаах дүн → хэтэвчээр эсвэл цэнэглээд төлөх → ПИН → төлөгдлөө

 16

Хувааж төлөх

Дурын дүн оруулах → ПИН → төлөгдлөө. Бүтэн дүн төлбөл зээл хаагдана.

17

Мэдэгдэл

Жагсаалт → мэдэгдэл бүр өөрийн хамаарах дэлгэц рүү: гүйлгээ → гүйлгээний дэлгэрэнгүй, арилжаа → бүтээгдэхүүн, зээл → зээлийн дэлгэц

 18

Профайл ба тохиргоо

Хувийн мэдээлэл, ПИН солих, нууц үг солих, хэл, мэдэгдлийн тохиргоо, тусламж

 19

Гэрээ, тодорхойлолт

Миний гэрээнүүд → гэрээ харах · хөрөнгө оруулалтын болон зээлийн тодорхойлолт хүсэх

 20

Мэдээ ба суралцах

Мэдээний хуудас → нийтлэл дэлгэрэнгүй → суралцах материал
Прототип дотор доод талын цэсээр бүх дэлгэц рүү үсрэх, зүүн дээд булангийн товчоор энэ жагсаалт руу буцах боломжтой. Гарын товчлол: ← буцах, → дараах.
